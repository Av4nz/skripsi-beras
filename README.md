# Backend (FastAPI)
Create your own venv and activate your venv  
For Windows:
```
cd backend
python -m venv venv
venv\Scripts\activate
```
For MacOS/Linux:
```
cd backend
python3 -m venv venv
source venv/bin/activate
```
Install the requirements.txt
```
pip install -r requirements.txt
```


# Frontend (Next.js)
Install the required packages:
```
cd frontend
bun install
```
